# 只有资料标题时，怎样用 AI 排学习顺序

> 目标：用公开标题和简介列出可核对的学习计划，遇到缺少的课程信息时知道该去哪确认。

假设你找到几份名字相似的教程，还没有打开正文。可以让 AI 帮你判断先看哪份，但它只能依据你给的信息。标题里出现“实战”，并不能证明教程有源码、习题或答案。

## 第一步：把能核实的信息做成卡片

每份资料只填三个字段：编号、公开标题、你实际看到的解释。版本、练习和先修要求可以留空。示例用下面三张虚构卡片即可练习：

| 编号 | 标题 | 可核实的简介 |
| --- | --- | --- |
| A | Python 入门语法 | 介绍变量、列表和循环 |
| B | 用表格文件做数据整理 | 说明用 Python 读取 CSV，要求已经会写循环 |
| C | 数据清洗项目实战 | 只有标题，课程版本和练习说明未知 |

真实材料可从任意公开学习网站选。投稿者维护的[资料星球 AI 与编程分类](https://resources.packscena.com/categories/ai/)也可以用来查看公开标题和条目介绍。只抄你已核实的介绍，保留编号用于对照，避免上传私人分享链接、提取码和个人信息。

## 第二步：把建议和依据放在同一行

可复制下面的指令，把表格放在末尾：

```text
我会写变量，但对列表和循环还不熟悉。
请根据下面的卡片，列一个两步的起步计划。每一步写：
1. 建议先看哪张卡，写出编号。
2. 依据是卡片里的哪句话，原样引述即可。
3. 一项我可以自己做的小练习，标为“AI 建议的练习”。

如果不知道某份资料的版本、先修要求或有没有练习，
写“待核实”，并说明我应检查简介、目录还是课程正文。
不要补写卡片没有提供的事实。

【将卡片表格放在这里】
```

## 第三步：检查哪些句子来自资料

核对 A 和 B 的顺序。卡片 B 明确要求会写循环，因此先看 A 有依据。如果模型说 C 附了项目源码，回到卡片 C。它只介绍了一个标题，这句话应改成“是否附源码待核实”。

AI 可能建议“用循环统计 CSV 的行数”。这是它为你设计的练习，不能据此写成“教程 B 有这道作业”。第一次做的时候，可以给计划中的每行标上“来源事实”“练习建议”或“待核实”。如果一条判断找不到对应卡片，就把它放到最后一类。

实际点开其中一份资料后，把你确认的新信息补回卡片。下一次只请 AI 更新受到影响的那一步，这样更容易追踪计划为什么变了。
